# 🔢 Binary & Boolean Calculator

A Python-based **command-line calculator** for binary arithmetic, number systems, bitwise operations, and Boolean algebra.

## ✨ Features

### Number Systems

- Binary → Decimal
- Decimal → Binary
-Binary ↔ Hexadecimal
-Binary→Octal




### Binary Operations

- Addition, subtraction, multiplication, integer division
- 1's complement
- 2's complement
- BCD
- Gray Code

### Bitwise Operations

- AND `&`
- OR `|`
- XOR `^`
- NOT
- Left Shift `<<`
- Right Shift `>>`

### Boolean Algebra

- AND / OR / XOR / NOT
- Boolean expression evaluator
- Parentheses and implicit AND
- Truth table generator
- Boolean expression simplification
- Step-by-step simplification
- Canonical SOP
- Canonical POS
- Input validation

## 🖥️ Interface

The project uses a simple menu-driven terminal interface:

```text id="0p3xq7"
╔══════════════════════════════════════════╗
║        BINARY & BOOLEAN CALCULATOR       ║
║                 V2.0                     ║
╚══════════════════════════════════════════╝

[1] Number System Conversion
[2] Binary Operations
[3] Bitwise Operations
[4] Boolean Algebra
[5] Exit
```
